# Telegram-бот для интеграции с Битрикс24

Бот принимает сообщения от пользователей и автоматически создаёт лиды в Битрикс24 через REST API.

## Технологии
- Python 3.14
- Flask (веб-сервер)
- requests (HTTP-запросы)
- python-dotenv (переменные окружения)

## Как запустить
1. Склонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` и укажите токены:
   T_token=ваш_токен_Telegram
   B_webhook=ваш_вебхук_bitrix24
4. Выполните bot.py - приложение запустит локальный сервер на http://127.0.0.1:5000 для приёма входящих вебхуков.
5. Обеспечьте публичный доступ к серверу, например, используя ngrok:
   1) в командной строке ngrok: 
     ngrok http 5000
   2) Скопируйте полученный HTTPS-адрес (например, https://abc123.ngrok-free.dev).
6. Зарегистрируйте вебхук в Telegram, выполнив запрос:
   https://api.telegram.org/bot<ваш_токен>/setWebhook?url=<ваш_HTTP-адрес_ngrok>
